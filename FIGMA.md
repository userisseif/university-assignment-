# FitSync Figma Prototype

The FitSync university assignment includes both low-fidelity wireframes and high-fidelity prototypes for the implemented website pages.

## Figma design

https://www.figma.com/design/AnOzNkM0V5WaNHVtN47kqz

## Prototype coverage

### Low-fidelity wireframes
- Home
- Timetable
- Class Details
- Create Class

### High-fidelity prototypes
- Home
- Timetable
- Class Details
- Create Class

The high-fidelity screens follow the structure and content of the HTML/CSS implementation in this repository, including navigation, class cards, timetable, class information, form controls, and footer.

## Accessibility considerations

The website implementation uses semantic HTML, descriptive navigation, alternative text for the logo image, a table caption and scoped table headings, form labels, keyboard focus styling, and readable foreground/background contrast.
